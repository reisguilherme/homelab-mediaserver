# Aceite do HomeServer

## Estado desta entrega

Os contratos e testes locais de domínio, SQLite, gateway, API, telemetria,
layout, backup e release estão implementados. Os critérios que dependem de
Legion, Tailscale, Docker em execução, Intel UHD, SFTP/Restic, Mosquitto TLS,
ESP32/CYD, clientes reais e ensaio de 48–72 horas permanecem `blocked_external`.

Isso é uma matriz de pendências, não uma declaração de aceite físico.
